# Webhooks and events

Arena sends an HTTPS `POST` to your endpoint when something happens, for example when a match completes or a purchase is refunded. Use webhooks instead of polling.

## Set up an endpoint

1. Create a public HTTPS endpoint that accepts `POST` with a JSON body.
2. Register it in the dashboard and choose the events you want.
3. Copy the signing secret. It starts with `whsec_`.
4. Return a `2xx` status within 10 seconds.

## Event payload

Every event uses the same envelope.

```json
{
  "id": "evt_5521",
  "object": "event",
  "type": "match.completed",
  "created_at": "2026-11-14T10:05:00Z",
  "mode": "test",
  "data": {
    "object": {
      "id": "mch_77",
      "object": "match",
      "status": "completed"
    }
  }
}
```

`data.object` holds the resource as it looked when the event happened.

## Verify the signature

Each request includes an `Arena-Signature` header.

```
Arena-Signature: t=1763114700,v1=5257a869e7ecebeda32affa62cdca3fa51cad7e77a0e56ff536d0ce8e108d8bd
```

To verify a request:

1. Split the header on commas to get `t` (timestamp) and `v1` (signature).
2. Build the signed string: the timestamp, a period, then the raw request body.
3. Compute an HMAC-SHA256 of that string with your signing secret.
4. Compare it to `v1` with a constant-time comparison.
5. Reject the request if `t` is more than 5 minutes old.

```js
import crypto from 'node:crypto'

export function verify(rawBody, header, secret) {
  const parts = Object.fromEntries(header.split(',').map((p) => p.split('=')))
  const signed = `${parts.t}.${rawBody}`
  const expected = crypto.createHmac('sha256', secret).update(signed).digest('hex')
  const fresh = Math.abs(Date.now() / 1000 - Number(parts.t)) < 300
  const a = Buffer.from(expected)
  const b = Buffer.from(parts.v1)
  return fresh && a.length === b.length && crypto.timingSafeEqual(a, b)
}
```

<Callout type="warning">
  Verify against the raw body. Parsing and re-serializing the JSON changes the bytes and breaks the signature.
</Callout>

## Retries

If your endpoint does not return `2xx`, Arena retries with exponential backoff: after 1 minute, 5 minutes, 30 minutes, 2 hours and 12 hours. After the last retry the event is marked failed. You can replay failed events from the dashboard for 30 days.

## Handle duplicates and ordering

- Delivery is at least once. Store each `id` you process and ignore repeats.
- Events can arrive out of order. Use `created_at`, or fetch the resource, before you act on state.
