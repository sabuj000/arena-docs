# Quickstart

In this quickstart you create a player, submit a score to the `weekly` leaderboard and read the player's rank. It takes about five minutes.

## Before you begin

You need a test server key. Test keys start with `sk_test_` and only touch sandbox data. See [Authentication](/docs/get-started/authentication) for how to get one.

<Callout type="warning">
  Keep server keys on your server. Never ship an `sk_` key in a game client.
</Callout>

## 1. Create a player

<CodeGroup>

```bash
curl https://api.arena.example/v1/players \
  -H "Authorization: Bearer sk_test_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"display_name": "NovaKnight"}'
```

```ts
const res = await fetch('https://api.arena.example/v1/players', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.ARENA_SECRET_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ display_name: 'NovaKnight' }),
})
const player = await res.json()
```

```python
import os
import requests

res = requests.post(
    "https://api.arena.example/v1/players",
    headers={
        "Authorization": f"Bearer {os.environ['ARENA_SECRET_KEY']}",
    },
    json={"display_name": "NovaKnight"},
    timeout=10,
)
player = res.json()
```

```php
<?php
$ch = curl_init('https://api.arena.example/v1/players');
curl_setopt_array($ch, [
    CURLOPT_POST => true,
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('ARENA_SECRET_KEY'),
        'Content-Type: application/json',
    ],
    CURLOPT_POSTFIELDS => json_encode(['display_name' => 'NovaKnight']),
]);
$player = json_decode(curl_exec($ch), true);
curl_close($ch);
```

</CodeGroup>

The response contains the player. Save the `id`.

```json
{
  "id": "plr_123",
  "object": "player",
  "display_name": "NovaKnight",
  "status": "active",
  "metadata": {},
  "created_at": "2026-11-14T10:00:00Z"
}
```

## 2. Submit a score

Send an `Idempotency-Key` so a retry never records the score twice.

<CodeGroup>

```bash
curl https://api.arena.example/v1/leaderboards/weekly/scores \
  -H "Authorization: Bearer sk_test_YOUR_KEY" \
  -H "Idempotency-Key: score-0001" \
  -H "Content-Type: application/json" \
  -d '{"player_id": "plr_123", "score": 4200}'
```

```ts
const res = await fetch('https://api.arena.example/v1/leaderboards/weekly/scores', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.ARENA_SECRET_KEY}`,
    'Idempotency-Key': 'score-0001',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ player_id: 'plr_123', score: 4200 }),
})
const score = await res.json()
```

```python
import os
import requests

res = requests.post(
    "https://api.arena.example/v1/leaderboards/weekly/scores",
    headers={
        "Authorization": f"Bearer {os.environ['ARENA_SECRET_KEY']}",
        "Idempotency-Key": "score-0001",
    },
    json={"player_id": "plr_123", "score": 4200},
    timeout=10,
)
score = res.json()
```

```php
<?php
$ch = curl_init('https://api.arena.example/v1/leaderboards/weekly/scores');
curl_setopt_array($ch, [
    CURLOPT_POST => true,
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('ARENA_SECRET_KEY'),
        'Idempotency-Key: score-0001',
        'Content-Type: application/json',
    ],
    CURLOPT_POSTFIELDS => json_encode(['player_id' => 'plr_123', 'score' => 4200]),
]);
$score = json_decode(curl_exec($ch), true);
curl_close($ch);
```

</CodeGroup>

```json
{
  "id": "scr_881",
  "object": "score",
  "leaderboard": "weekly",
  "player_id": "plr_123",
  "score": 4200,
  "rank": 1,
  "submitted_at": "2026-11-14T10:01:00Z"
}
```

## 3. Read the rankings

<CodeGroup>

```bash
curl "https://api.arena.example/v1/leaderboards/weekly/entries?limit=10" \
  -H "Authorization: Bearer sk_test_YOUR_KEY"
```

```ts
const res = await fetch('https://api.arena.example/v1/leaderboards/weekly/entries?limit=10', {
  headers: {
    Authorization: `Bearer ${process.env.ARENA_SECRET_KEY}`,
  },
})
const entries = await res.json()
```

```python
import os
import requests

res = requests.get(
    "https://api.arena.example/v1/leaderboards/weekly/entries?limit=10",
    headers={
        "Authorization": f"Bearer {os.environ['ARENA_SECRET_KEY']}",
    },
    timeout=10,
)
entries = res.json()
```

```php
<?php
$ch = curl_init('https://api.arena.example/v1/leaderboards/weekly/entries?limit=10');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('ARENA_SECRET_KEY'),
    ],
]);
$entries = json_decode(curl_exec($ch), true);
curl_close($ch);
```

</CodeGroup>
