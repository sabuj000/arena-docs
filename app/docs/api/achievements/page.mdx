# Achievements

An achievement is a milestone a player can earn once, for example `first_win`. Achievements are defined in the dashboard. The API lists them and records when a player unlocks one.

## The achievement object

```json
{
  "id": "ach_first_win",
  "object": "achievement",
  "key": "first_win",
  "name": "First win",
  "description": "Win your first ranked match.",
  "hidden": false
}
```

## List achievements

<Endpoint method="GET" path="/v1/achievements" />

Returns all achievements that are not hidden. Works with a publishable key.

<Snippets operation="GET /achievements" />

## List a player achievements

<Endpoint method="GET" path="/v1/players/{player_id}/achievements" />

Returns the achievements the player has unlocked, including hidden ones, with the time of each unlock.

```json
{
  "object": "list",
  "data": [
    { "achievement_id": "ach_first_win", "unlocked_at": "2026-11-14T10:05:00Z" }
  ],
  "has_more": false,
  "next_cursor": null
}
```

<Snippets operation="GET /players/{player_id}/achievements" />

## Unlock an achievement

<Endpoint method="POST" path="/v1/players/{player_id}/achievements/{achievement_id}/unlock" />

Records that the player unlocked the achievement. Requires a secret key. Sends `achievement.unlocked`.

<Snippets operation="POST /players/{player_id}/achievements/{achievement_id}/unlock" />

```json
{
  "achievement_id": "ach_first_win",
  "player_id": "plr_123",
  "unlocked_at": "2026-11-14T10:05:00Z"
}
```

Unlocking is safe to repeat. If the player already has the achievement, the request returns `200` with the original `unlocked_at` and no second event is sent.
