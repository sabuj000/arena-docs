## Make your first request

Create a player, then submit a score. You need a test server key from the sandbox. See [Authentication](/docs/get-started/authentication).

<CodeGroup>

```bash
# Create a player
curl https://api.arena.example/v1/players \
  -H "Authorization: Bearer sk_test_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"display_name": "NovaKnight"}'
```

```bash
# Submit a score
curl https://api.arena.example/v1/leaderboards/weekly/scores \
  -H "Authorization: Bearer sk_test_YOUR_KEY" \
  -H "Idempotency-Key: score-0001" \
  -H "Content-Type: application/json" \
  -d '{"player_id": "plr_123", "score": 4200}'
```

</CodeGroup>
